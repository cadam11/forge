This section will hold one guide per shipped surface: the query editor, the results grid,
execution plans, the object explorer, object search, the command palette, snippets, query
history, the ERD, schema diff, backup and restore, database operations, Docker containers, SQL
dialect conversion, the AI assistant and AI setup.

They are being written now and are not here yet. Until then:

- The [README's feature list](https://github.com/cadam11/joinery#features) is the current
  overview.
- Inside the app, **⇧⌘/** opens the keyboard-shortcut cheat sheet and **⌘K** opens the command
  palette, which lists every command with its description and binding.
- [A tour of the workspace](../getting-started/workspace-tour/) already names every region these
  guides will refer to.

Two prerequisites some of these features depend on — the PostgreSQL and MySQL backup CLIs, and
Python with sqlglot for dialect conversion — are documented in full on
[Prerequisites](../getting-started/prerequisites/).
