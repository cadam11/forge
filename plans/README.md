# About this directory

The product is now named **Joinery**; it was previously "Forge" and, before
that, "MJ Forge." The design and planning documents in this directory are dated
engineering logs written before those renames. Product-name references in them
have been updated to Joinery, but their substance has not been rewritten — they
still describe the scope, constraints, and MemberJunction integrations of the
time, some of which have since been removed or replaced.

For the current state of the project, see the root `README.md`, `CLAUDE.md`,
and `plans/rebrand/FOLLOW-UPS.md`.
