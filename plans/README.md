# About this directory

This project was renamed from "MJ Forge" to "Forge." The design and planning
documents in this directory are dated engineering logs written before that
rename — they refer to the project by its old name, and to MemberJunction
integrations that have since been removed or replaced. They are kept as-is,
as historical record, and are not being rewritten to match current naming.

For the current state of the project, see the root `README.md`, `CLAUDE.md`,
and `plans/rebrand/REBRAND-PLAN.md`.
